# Project page

Static page served at https://anonymous.4open.science/w/task-order-cl-4f7b/. It uses only local HTML, CSS, JavaScript, figures, and data. `assets/results.js` embeds the same order-level means and sample standard deviations as `assets/results.json`, so the interactive comparison works without network requests; `assets/paper.pdf` is the anonymous review build of the manuscript.
