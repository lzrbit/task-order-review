What Is the Influence of Task Order in Continual Learning?

An Empirical Study and Order-Aware Evaluation for Motion Forecasting

Same tasks. Different order. Different ranking.

Overview

An algorithm’s advantage depends on its learning history.

Continual learning asks a model to acquire new knowledge while retaining what it has already learned. But the same tasks can arrive in different sequences—and an algorithm that leads on one sequence may fall behind on another.

We study this dependence in motion forecasting. Algorithms share the task set, prediction backbone, and evaluated orders. Across all 24 orders of four tasks, task order accounts for 65 to 91 percent of the variation in current-task error and backward transfer, but 90 to 99 percent of that share is the identity of the starting task, which acts through the cold start of the smallest task. Beyond the first stage, the order effect is comparable to training variability. A transition-direction descriptor adds a common weighting policy; on this task set it mainly indexes where the smallest task is placed.

Empirical setting

Four traffic scenarios, distinct distributions.

We group twelve INTERACTION location subsets into urban merging, highway merging, intersections, and roundabouts. All four methods use the same UQnet endpoint predictor.

  • AUrban merge
  • BHighway merge
  • CIntersection
  • DRoundabout
Four learning strategies · shared UQnet backbone24 task orders, with three training repetitions per method and order (288 archived runs).

Feature summaries pool historical time-step observations within each task; these observations are not independent trajectories.
